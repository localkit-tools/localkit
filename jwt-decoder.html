What is a JWT Decoder?

    
A JWT decoder displays the header and payload of a JSON Web Token in readable JSON format. JWTs are commonly used to pass claims between applications and services.

Privacy and security

    
This tool decodes the token in your browser. Decoding does not verify the signature or prove that a token is authentic. Never paste real passwords, private tokens, or sensitive production credentials into online tools.
