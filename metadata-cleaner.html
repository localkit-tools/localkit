Free Image Metadata Cleaner

Create a new PNG copy of an image by drawing it onto a browser canvas. This can remove many types of embedded metadata from the newly created image.

Clean Image Metadata

Maximum file size: 15 MB. Images with more than 40 million pixels are not processed.

How to Use

  1. Select an image file from your device.
  2. Click Clean Image.
  3. Wait for processing to finish.
  4. Click Download Cleaned Image to save the new PNG.

Privacy: The image is processed in your browser; this tool does not upload it to a server. For sensitive images, use a trusted device and keep the original file if you need it.

Important: The result is a PNG copy, so the file format and file size may change. Canvas conversion can remove many embedded metadata fields, but this tool does not guarantee removal of every possible metadata type or hidden information. Check the downloaded file if you require verified metadata removal.
