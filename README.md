LocalKit — Private Browser Tools

LocalKit is a collection of simple browser-based tools designed to make everyday developer tasks easier.

Features

- JSON Formatter — Format and validate JSON.
- JWT Decoder — View the header and payload of a JSON Web Token.
- Base64 Encoder/Decoder — Encode and decode text.
- URL Encoder/Decoder — Encode and decode URL components.
- Timestamp Converter — Convert Unix timestamps into readable dates.
- Regex Tester — Test regular expressions against sample text.
- SHA-256 Generator — Generate a SHA-256 hash from text.
- Metadata Cleaner — Re-encode supported images as PNG files.
- Password Generator — Generate random passwords.
- Password Strength Checker — Get a basic password-strength estimate.

Privacy

LocalKit is designed to process tool inputs in the browser wherever possible. The website's hosting provider and browser may still process technical information.

- Avoid entering sensitive or confidential information.
- JWT decoding does not verify a token's signature.
- The password-strength checker provides only a basic estimate.
- Image re-encoding may remove some metadata, but it does not guarantee removal of every metadata field.
